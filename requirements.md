# IZUBA App - Full-Stack MVP Product Requirements Document

## 1. Project Overview

A fully functional, multi-tenant B2B AgTech MVP. The platform connects rural mushroom farmers with urban restaurants, utilizing a Just-In-Time algorithmic order model to reduce spoilage to 0%.

## 2. Tech Stack Architecture

- **Frontend:** React (Vite) or Next.js.
- **Styling:** Tailwind CSS + Framer Motion (for smooth page transitions).
- **Icons:** `lucide-react`.
- **Backend/Database:** Firebase or Supabase (Agent: Suggest the fastest data schema for a 14-hour build).

## 3. Required User Flows & Screens (Creative Freedom Encouraged)

_Agent: You are encouraged to expand on these and suggest additional screens or flows if they improve the MVP's pitch value._

- **Flow 1: Consumer / Traceability Experience (Public)**
  - A beautiful landing page triggered by a QR scan. Shows the "Farm-to-Fork" story, live harvest stats, and an embedded recipe video.
- **Flow 2: Restaurant B2B Portal (Authenticated Buyer)**
  - A seamless ordering interface. Buyers can see "Available Yield," place just-in-time orders, and track their delivery status.
- **Flow 3: Farmer / Admin Ledger (Authenticated Supplier)**
  - A comprehensive digital dashboard. Tracks active mushroom tubes, upcoming B2B fulfillment requirements, gross revenue, and a visual log of Biomass waste sold for secondary income.
